# Mahashi Website

A Next.js 15 website scaffolded with TypeScript, Tailwind CSS, and the App Router.

## Getting Started

Install dependencies:

```bash
npm install
```

Run the development server:

```bash
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) in your browser.

## Scripts

- `npm run dev` starts the local development server.
- `npm run build` creates a production build.
- `npm run start` starts the production server after building.
- `npm run lint` runs Next.js linting.
- `npm run typecheck` runs TypeScript checks.

## Vercel Deployment

This project is ready for Vercel. Import the repository in Vercel and use the defaults:

- Framework Preset: Next.js
- Build Command: `npm run build`
- Install Command: `npm install`
- Output Directory: `.next`

Add environment variables in Vercel Project Settings when the site needs them.
